# 语言与心境审计：从「骂人判不出」到短消息被丢弃

> 版本：0.3.1 工作区（2026-11-13）
>
> 触发反馈：`你怎么这么笨，闭嘴` 仍是 `neutral`；单条消息心境只推 0.01；18 小时时间常数对日常聊天太迟钝。
>
> 一句话结论：**这不是两个独立的小问题，而是三层叠加的失败。** 第一层是中文否定的字符窗口写错，把「特别」「别人」「差不多」里的否定字当成了否定；第二层是词典只覆盖书面情绪词，漏掉口语攻击、感谢/夸奖、重大损失；第三层更隐蔽——短而强的消息在 `AgentMemory.estimate_importance` 里被长度规则判成低重要性，根本没有进入 `perceive`，所以即使分类器修好，心境也不会动。三层都修完后，30 轮本地 35B 定向长测 30/30 通过，单条辱骂心境变化约 -0.054，单条感谢约 +0.059，日常 30 轮心境范围约 0.232。

---

## 1. 用户反馈的复现

修复前，用同一套 `estimate_appraisal` + `appraise` 直接检查：

| 输入 | 修复前标签 | 问题 |
|---|---|---|
| `你怎么这么笨，闭嘴` | `neutral` | 口语攻击完全漏检 |
| `别烦我` | `joy` | `别` 被当成通用否定，反转了「烦」 |
| `今天特别开心` | `sadness` | `特别` 里的「别」被当成否定 |
| `我特别喜欢这个方案` | `sadness` | 同上 |
| `别人夸我今天的报告` | `sadness` | `别人` 里的「别」被当成否定 |
| `谢谢你，辛苦了` | `neutral` | 感谢/辛苦不在词典 |
| `项目黄了` | `neutral` | 重大损失不在词典 |
| `你可真厉害啊` | `neutral` | 讽刺无法与真夸区分 |

这些不是「词表少几个词」的问题。`特别开心` 和 `别人夸我` 的极性被**反转**，说明否定算法本身有 bug；在这个基础上继续加词，只会把新词也弄反。

## 2. 根因一：两字符否定窗口

旧实现：

```python
def _negated(text: str, index: int) -> bool:
    window = text[max(0, index - 2):index]
    return any(n in window for n in NEGATORS)
```

它只看目标词前两个字符里有没有 `不/没/无/别/未`。中文里大量词**包含**这些字，但不是否定：

- `特别` 含 `别`；
- `别人` 含 `别`；
- `差不多` 含 `不`；
- `不断`、`不仅`、`不但` 含 `不`；
- `无论`、`未来`、`未免` 含 `无/未`。

修复后，否定窗口改成**分句内的局部窗口 + 显式例外 + 双重否定**：

1. 先按 `，。！？；` 切分，只看当前分句；
2. 如果窗口以 `特别/别人/差不多/不断/...` 结尾，或否定字位于这些词的内部，跳过；
3. `不是不/并非不/不能不/不得不/无不/没有不` 视为双重否定，不翻转；
4. `没想到` 不把后面的情绪词翻转（它是「意外」线索，不是否定情绪）；
5. 词内非情绪对象用 `WORD_EXCEPTIONS` 处理，例如 `积累/累计` 里的「累」、`病人/病历/病毒` 里的「病」、`夸克` 里的「夸」、`麻烦你` 里的「烦」。

新增回归覆盖：

- `今天特别开心`、`我特别喜欢这个方案`、`别人夸我今天的报告`、`差不多完成了`、`不断进步` 必须为正；
- `今天不开心`、`我不喜欢这个方案`、`别烦我` 必须为负；
- `我不是不喜欢这个方案` 不被当成否定；
- `我在看垃圾分类`、`我在滚面团`、`蔬菜很新鲜`、`我在积累经验`、`我在夸克上查资料` 必须为中性。

## 3. 根因二：词典只认书面词

旧词典能识别 `失败/难过/生气/焦虑/害怕/累/烦/病`，但中文口语里的攻击、感谢、夸奖和损失大量不在这张表里。

### 3.1 新增的口语影响线索

不是继续堆一个巨大的情感词表，而是引入 `LexicalCue`：每个线索除了极性，还带 `agency / control / stakes / norm / confidence`，并写入 `Appraisal.note`，便于审计。

| 类别 | 例子 | 处理 |
|---|---|---|
| 直接侮辱 | `你怎么这么笨，闭嘴`、`你是不是傻`、`你真是个废物`、`你就是个垃圾` | `direct_insult`，负向，other agency |
| 能力贬低 | `菜得抠脚`、`菜鸡`、`弱爆了`、`蠢死了`、`笨死了` | `ability_insult` |
| 医学化侮辱 | `脑子有病`、`神经病`、`你是不是有病` | `medical_insult`；`神经病学/科/院` 不触发 |
| 命令/驱逐 | `闭嘴`、`少废话`、`别烦我`、`滚蛋`、`滚`、`要你何用`、`没用的东西` | `imperative_attack`；`滚面团` 不触发 |
| 轻蔑 | `就这？`、`不过如此`、`一般般` | `dismissal`，轻度负向 |
| 转述贬低 | `别人说我笨`、`他说我傻` | `reported_insult` |
| 感谢/夸奖 | `谢谢`、`辛苦了`、`你真好`、`太厉害了`、`牛啊`、`靠谱`、`给力`、`你帮我大忙了` | `gratitude` / `praise` / 正向词 |
| 关心/支持 | `朋友一直陪着我，安慰我`、`别难过`、`加油` | `care` |
| 重大损失 | `项目黄了`、`我被裁了`、`我们分手了`、`家人生病了`、`我被骗了`、`我亏钱了` | `job_loss` / `relationship_loss` / `health_crisis` / `betrayal` / `project_loss` / `setback` |
| 自我贬低 | `我真笨`、`我太蠢了`、`我是个废物` | `self_deprecation`，self agency |

同时加了防误伤边界：

- `垃圾分类/垃圾桶/垃圾回收/垃圾食品` 不触发「垃圾」攻击；
- `菜市场/菜谱/菜单/菜园/菜地/菜刀` 不触发「菜」攻击；
- `滚面团` 不触发「滚」；
- `讲笑话` 不触发「笑话」；
- `没用这个/没用多久` 不触发「没用」；
- `麻烦你了` 不触发「烦」的负向，反而作为礼貌感谢；
- `不辛苦`、`不麻烦你了` 作为礼貌性正向短语。

### 3.2 不再强行解释歧义

`呵呵`、`卧槽`、`他妈的`、`你可真厉害啊`、`好棒棒`、`你可真行啊` 这类高度依赖语境的表达，不再硬判强负向，而是：

- `certainty` 降到 0.35；
- `note` 记录 `ambiguous:sarcasm` 或 `ambiguous:profanity`；
- 只在没有其他明确线索时给一个很小的负向 nudge（约 -0.12 到 -0.18），保持 `neutral`；
- 不把「他妈的」当成对用户的直接攻击，也不把「你可真厉害啊」当成真夸。

这是**有意的保守**：在只有文本、没有语调/表情/前文的情况下，硬判讽刺的假阳性会比漏判更伤害体验。后续如果接入对话历史，应把「上一轮是否冲突」「是否引用对方原话」作为特征，而不是继续加词。

## 4. 根因三：短消息被重要性门槛丢掉

这是本轮审计里最重要的新发现，也是「单条消息心境只推 0.01」的直接原因之一。

`AgentMemory.observe()` 先算 `estimate_importance(text)`，低于默认 `min_importance=0.35` 就直接返回 `None`，不会调用 `mind.perceive()`，因此：

- 不写入情景记忆；
- 不产生情绪冲量；
- 不影响心境、压力、内分泌。

旧 `estimate_importance` 的兜底是：

```python
if len(text) < 12:
    return 0.30
```

于是这些**又短又强**的消息全部被丢掉：

| 消息 | 旧重要性 | 结果 |
|---|---:|---|
| `闭嘴` | 0.30 | 丢弃，心境 0 |
| `你真是个废物，滚蛋` | 0.30 | 丢弃，心境 0 |
| `你真好，靠谱` | 0.30 | 丢弃，心境 0 |
| `太厉害了，牛啊` | 0.30 | 丢弃，心境 0 |
| `谢谢你，辛苦了` | 0.45（长度 >12） | 保留，但旧分类为 neutral |

第一次 30 轮定向长测里，第 6、13、15、21、22 轮的 `mood_before` 与 `mood_after` 完全相等，就是这条路径造成的。分类器修好了，但消息根本没进引擎。

修复：`estimate_importance` 在纯 smalltalk 之后、长度兜底之前，先跑一次轻量评价；如果 `abs(desirability) >= 0.30`，直接给 0.85 的重要性。这样：

- `闭嘴`、`你真是个废物`、`你真好`、`太厉害了`、`项目黄了` 都会进入 `perceive`；
- `嗯/谢谢/晚安` 这类纯 smalltalk 仍然走 0.20，不会把所有寒暄都写进长期记忆；
- 事实问题、提醒、承诺的原有规则不变。

新增测试：

- `estimate_importance("闭嘴") >= 0.7`；
- `estimate_importance("你真是个废物") >= 0.7`；
- `estimate_importance("你真好") >= 0.7`；
- `estimate_importance("项目黄了") >= 0.7`；
- `AgentMemory.observe("闭嘴")` 返回非空，且心境下降。

## 5. 心境动力学校准

### 5.1 旧参数的问题

旧默认：

```text
mood_tau_hours = 18.0
mood_reactivity = 0.18
```

`apply_emotion` 里：

```python
mood += mood_reactivity * dv
```

`step` 里：

```python
target = setpoint + environment + hormone + circadian + 0.45 * valence
mood = first_order(mood, target, dt, mood_tau_hours)
```

即使把 `你怎么这么笨，闭嘴` 强行分类成负向，旧参数下单条即时心境也只有约 -0.024；而旧分类是 neutral，实际是 0。日常聊天的事件强度通常低于强辱骂，于是「聊一天几乎不动」。

### 5.2 新默认与敏感性

新默认：

```text
mood_tau_hours = 10.0
mood_reactivity = 0.40
```

这不是「拍脑袋把 tau 调小」。做了 6/8/10/12/15/18 小时 × 0.30/0.40/0.50 的扫描，关注四个量：

1. 单条强辱骂的即时变化；
2. 24 小时后的残余；
3. 单条轻微负面（`今天有点累`）是否仍可见；
4. 30 轮日常聊天的心境范围与压力峰值。

| tau / mr | 辱骂即时 | 辱骂 24h 残余 | 有点累即时 | 感谢即时 | 30 轮范围 | 压力峰值 |
|---|---:|---:|---:|---:|---:|---:|
| 6 / 0.30 | -0.0401 | -0.0007 | -0.0230 | +0.0438 | 0.0791 | 0.253 |
| **10 / 0.40** | **-0.0535** | **-0.0049** | **-0.0307** | **+0.0585** | **0.1004** | **0.253** |
| 18 / 0.40 | -0.0535 | -0.0141 | -0.0307 | +0.0585 | 0.0987 | 0.253 |
| 18 / 0.18（旧） | -0.0241 | -0.0064 | -0.0138 | +0.0263 | — | — |

读法：

- 即时变化只由 `mood_reactivity` 和情绪强度决定，与 tau 无关；
- tau 主要影响 24 小时残余和日常累积形状；
- 10h 让 24h 残余约 -0.005，仍会在第二天早上留下一点痕迹，但不会把一次事件拖成一周；
- 18h 的 24h 残余更大（-0.014），但单条即时仍只有 -0.024，说明**只调 tau 解决不了「单条太弱」**；必须同时提高事件反应性，并修复短消息丢弃；
- 30 轮范围在 10/0.40 下约 0.100，定向长测（含更强事件）约 0.232。

### 5.3 产品语义的修正

旧 README 说「心境是好几天的慢变量」。在新参数下，更准确的说法是：

> 情绪是小时级（默认 1.1h 半衰期）；心境是数小时到一天的慢变量；更慢的内分泌/适应负荷层（30h/240h）承担「几天」的背景。

这不是把「慢」删掉，而是把不同时间尺度分开：

- 情绪：`emotion_tau_hours=1.1`；
- 心境：`mood_tau_hours=10`；
- 压力：`stress_tau_hours=5`；
- 内分泌：以皮质醇/血清素等半衰期和 HPA 级联表示；
- 适应负荷：`allostatic_tau_hours=240`。

10h 是**聊天回合密度下的工程折中**，不是生理常数，也没有做个体拟合。报告里必须这样写，避免把参数当成科学结论。

## 6. 事实、意图与否定边界

### 6.1 事实抽取的否定误报

审计发现：

| 输入 | 旧行为 | 新行为 |
|---|---|---|
| `我不住在上海` | 抽到 `city=上海` | 不抽 |
| `我不在上海工作` | 抽到 `city=上海`、`job=软件` | 不抽 |
| `我不做软件` | 抽到 `job=软件` | 不抽 |
| `我对花生不过敏` | 抽到 `allergy=花生` | 不抽 |
| `我不吃香菜` | 抽到 `food_dislike=香菜` | 保留（这是有效偏好） |

修复是保守的前缀否定守卫：只在 `city/job` 规则前检查 `不/没/没有/并非/不是/别`，在 `allergy` 捕获值里检查否定字，在 `sleep/wake` 值以否定字开头时跳过。没有把它做成通用否定解析器；复杂条件、引语、跨句指代仍然可能出错。

### 6.2 意图分类

`classify_intent` 的情绪线索也扩了：

- `你怎么这么笨，闭嘴` → `affective`；
- `谢谢你，辛苦了` / `你真好` → `affective`；
- `项目黄了` → `mixed`（事实「项目」+ 情绪「黄了」）；
- `我们分手了` → `affective`；
- `这个 API 报错怎么办` → `technical`；
- `他住哪？` → `factual`。

这保证情绪事件不会因为「看起来像事实句」而被门控关掉。

## 8. 与已有研究的关系

这一节只写「哪些是证据、哪些是工程假设」。

### 8.1 情绪持续时间

Fan 等（2019）用在线情绪标注的分钟级数据指出，情绪事件的时间尺度在分钟到小时量级，且受标注/评价影响。Thymos 的 `emotion_tau_hours=1.1` 与这一量级相容，但不是从该论文拟合出来的常数。

### 8.2 评价与核心情感的日常耦合

Kuppens 等（2012）用经验采样展示评价与核心情感在日常生活中的动态耦合。Thymos 的「评价 → 情绪冲量 → 心境」结构借用了这个方向，但具体权重（`mood_reactivity=0.40`、`0.45 * valence`）是工程参数。

### 8.3 中文攻击性语言与讽刺

Xiao、Bouamor 与 Zaghouani（2024）的中文攻击性语言综述指出，中文攻击性语言受文化、语境、隐晦表达影响，单靠词表不足。Lin 与 Hsieh（2016）的中文讽刺语料也说明讽刺高度依赖上下文。

这支持本轮的策略：

- 明确的口语攻击用短语线索兜底；
- 讽刺/泛化脏话不硬判，降 certainty 并记录 `ambiguous`；
- 下一步应接入对话历史/引用检测，而不是继续扩大词表。

### 8.4 中文情感词典的许可

调研了 NTUSD、HowNet、DUTIR 情感词汇本体等资源：

- DUTIR 情感词汇本体在公开说明中标注为学术研究用途，不能直接当作 MIT 代码库的商用词典打包；
- NTUSD 的再分发条款需要逐项确认；
- 这些词典主要覆盖书面情感词，对「闭嘴/滚蛋/菜得抠脚/你真好/项目黄了」这类口语/事件线索覆盖有限。

因此本轮**没有**把第三方词典直接塞进仓库，而是维护一个小的、可审计的本地基线；如果未来引入，必须先做许可证审核、质量评估和版本锁定。

## 9. 仍然存在的边界

这一节是「不要过度宣称」的清单。

1. **讽刺、引用、转述仍未真正理解。** `你可真厉害啊` 现在保持 neutral + ambiguous；`他说你笨` 仍会负向（内容确实负面），但没有区分「引用」与「直接攻击」。真正的引用/说话人归因需要句法或对话历史。
2. **偏好陈述与当下情绪没有分开。** `我喜欢吃火锅` 仍会被标成 `joy`；它其实是稳定偏好，不应每次影响心境。下一步应在意图层增加 `preference`，或在评价层区分「 dispositional liking」与「episodic joy」。
3. **轻蔑语会偏负。** `就这？`、`一般般`、`不过如此` 被 `dismissal` 标成轻度负向（约 -0.35），不是 neutral。这是有意的，但可能对玩笑语境过度反应。
4. **技术词仍有歧义。** `通过 API 调用` 已不再因为「通过」被判正；但 `问题`、`bug`、`安全` 等词在技术语境仍可能产生情绪噪声。意图门控能降低影响，但不能完全消除。
5. **事实否定只覆盖了 city/job/allergy/sleep/wake。** 其他谓词、条件句、引语、跨句指代仍可能误抽。
6. **50 轮猫探针有一次 top-k 漏检。** 不是事实删除；需要检索排序/关键词增强，暂列 P2。
7. **参数不是拟合结果。** 10h/0.40 是在敏感性扫描和产品需求之间选的工程值；没有个体基线校准，也没有多日 EMA 数据。
8. **长虚拟天的疲劳会到 1.0。** 50 轮脚本跨了多天、睡眠不足时疲劳饱和；这会通过巩固质量影响长期记忆。它不是本轮语言修复的核心，但应在睡眠/作息场景单独审计。
9. **单模型、单种子、无人工盲评。** 30 轮和 50 轮是集成测试，不是统计基准；不能据此声称「中文情绪识别准确率」。
