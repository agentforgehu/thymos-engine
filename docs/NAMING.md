# 命名说明：为什么叫 Thymos / 心潮

> 调研日期：2026-11-11 至 2026-11-12。名称占用会变化，发布前应重新核查。

## 1. 结论

| 项目 | 名称 |
|---|---|
| 英文品牌 | **Thymos** |
| 中文品牌 | **心潮** |
| GitHub 仓库 | `thymos-engine`（`thymos` 已被多个无关项目占用） |
| PyPI 发行名 | `thymos-engine`（发布前需再次确认） |
| Python 导入名 | `thymos` |
| 命令行 | `thymos` |
| 一句话 | 记忆会褪色，情绪会涨落。Thymos 让 Agent 记得为什么。 |

## 2. 词源与语义

**Thymos（θυμός）** 是古希腊语，含义包括“血气、激情、精神、勇气、愤怒”。在柏拉图的灵魂三分中，它与理性（logos）和欲望（epithymia）并列，代表**有方向的情感驱力**——不是被动感受，而是“被什么打动、为什么行动”。

它恰好覆盖了本项目的两个核心：

- **情绪**：评价产生情绪，情绪给记忆加权；
- **驱力**：内分泌与心境不是装饰，而是改变编码、提取和行为的参数。

中文名 **心潮** 取“心绪如潮，有涨有落”：

- 潮汐有节律（昼夜、季节、光照）；
- 潮水会退（遗忘），也会再来（提取、复习）；
- 每一次涨落都改变岸线（再巩固会改写记忆）。

相比“情绪引擎”“记忆系统”这类功能名，**Thymos / 心潮** 同时表达了“动力学”和“人味”，又不会承诺它其实做不到的事情（例如“有意识”）。

## 3. 占用核查

### GitHub

| 查询 | 结果（2026-11-12） | 判断 |
|---|---|---|
| `thymos in:name` | 52 个仓库 | 拥挤 |

| `gryszzz/open-thymos` | 一个 Agent 运行时/沙箱 | 同一领域，高混淆 |
| `FredHutch/thymosight` | 生物信息学工具 | 中混淆 |
| `thymos-engine in:name` | **0 个仓库** | 可用 |
| `mnethos` | 3 个仓库，含 Mnethos CLI 的 Homebrew tap | 已占用 |
| `mnema in:name` | 88 个仓库，含 AI 长期记忆项目 | 拥挤 |
| `sillage in:name` | 392 个仓库 | 非常拥挤 |

### PyPI

PyPI 的 JSON/Simple 页面在当前网络环境下无法稳定读取，因此**没有把“PyPI 可用”当成既成事实**。发布前必须执行：

```bash
pip index versions thymos-engine
# 或在浏览器打开 https://pypi.org/project/thymos-engine/
```

若 `thymos-engine` 也被占用，备选发行名：

1. `thymos-core`
2. `xinchao`
3. `thymos-lab`

导入名保持 `thymos` 不变，避免用户代码跟着发行名变化。

### 结论

- 品牌层用 **Thymos / 心潮**，语义最准，记忆点最强；
- 工程层用 **`thymos-engine`**，避开已有同名项目，且 GitHub 当前为零占用；
- 文档与 README 首次出现时明确“Thymos 是项目名，`thymos-engine` 是仓库/发行名”，减少搜索混淆。

## 5. 品牌系统

### 标志

- 主符号：希腊字母 **θ**（theta），既是 Thymos 的首字母，也像一条被潮水切开的岸线。
- 中文标准字：**心潮**（思源黑体 / 微软雅黑，字重 600）。
- 图形语言：等值线、潮汐曲线、细网格；避免大脑、神经元、心形等陈词滥调。

### 色板

| 用途 | 色值 | 含义 |
|---|---|---|
| 背景 | `#0A0E13` | 深夜、静息 |
| 面板 | `#111821` | 可读的暗面 |
| 主色 | `#3DDC97` | 潮水、恢复、可提取 |
| 次色 | `#7C9CFF` | 血清素、冷静 |
| 暖色 | `#F2B880` | 皮质醇、警觉 |
| 警示 | `#FF7A90` | 高唤醒、压力 |

### 语气

- 说“模型认为”，不说“系统知道你在想什么”。
- 说“在当前参数下”，不说“科学证明”。
- 说“可提取度”，不说“记忆强度”（后者容易被理解为永久）。
- 不使用“治愈”“懂你”“比人更懂你”等承诺。
