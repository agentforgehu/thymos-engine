# 100 轮长测：事实、更新、重复、情绪与写路径

> 这是作者构造的场景测试，不是真人用户研究。它验证“系统在长对话里是否稳定、是否按设计运行”，不证明“用户会满意”。

## 1. 为什么要 100 轮

30/50 轮能暴露短程问题，但暴露不了：

- 早期事实在几十轮后还能不能被查到；
- 新旧事实冲突时，旧值会不会被回写；
- 重复/改写会不会把记忆库撑大；
- 多次强情绪后，心境/压力是否仍有界；
- SQLite 在真实写入节奏下是否正常；
- 混合“事实 + 情绪”查询会不会被门控误伤。

脚本：`experiments/longrun_100.py`。场景覆盖：

| 段落 | 轮次 | 内容 |
|---|---|---|
| 建立事实 | 1–10 | 姓名、城市、职业、项目、截止日期、过敏、宠物、家人 |
| 日常生活 | 11–20 | 咖啡、火锅、看牙、下雨、夸奖、焦虑、睡眠 |
| 强情绪 | 21–30 | 辱骂、驱逐、讽刺、项目失败、分手、关心、夸奖、混合 |
| 更新/重复 | 31–40 | 搬家、项目改名、旧截止日期复述、精确重复、改写、换工作 |
| 重复/健康 | 41–50 | 精确重复、改写、滚面团/垃圾分类/蔬菜等中性对象、吉他、睡眠 |
| 工作压力 | 51–60 | 改需求、甩锅、老板夸奖、加班、修 bug、跑步、爬山、坚果 |
| 家人/宠物 | 61–70 | 妈妈生日、爸爸喝茶、恩施、猫肠胃炎、出差、海鲜过敏 |
| 混合/损失 | 71–80 | 累+过敏、压力+截止、工作+地址、建议、辱骂、讽刺、裁员、offer |
| 二次搬家 | 81–90 | 新公司、新工位、新地址、旧地址作废、项目交付、推荐信、猫送回恩施 |
| 收尾 | 91–100 | 婚礼、休息、感谢、夸奖、轻微贬低、最终事实探针、晚安 |

## 3. 真实模型

命令：

```bash
python experiments/longrun_100.py --fresh --turns 100 \
  --embedding llamacpp --embedding-url http://127.0.0.1:8081/v1 \
  --embedding-model bge-small-zh --max-chars 900 --max-tokens 160
```

模型：本地 `qwen3.6-35b-a3b`（llama.cpp，Q4_K_M，32K 上下文，`--n-cpu-moe 34`）。
嵌入：本地 `bge-small-zh-v1.5-q8_0.gguf`（llama.cpp embedding server，512 维）。
状态：`.work/longrun100/state.sqlite`（SQLite 状态后端）。

### 3.1 读法

- **上下文探针**：检查 `plan()["context"]` 是否包含预期事实；这是记忆层的能力。
- **回答探针**：检查模型是否真的用了上下文；这会受模型本身影响，不能全算在记忆层头上。
- **写决策**：`store/merge/reinforce/skip` 是写路径的行为，不是模型行为。
- **标签**：规则评价在强情绪句上的标签；讽刺句不设硬期望，避免把“故意不硬判”当成失败。

## 4. 失败与边界

无论结果如何，以下边界不变：

1. 100 轮是作者构造的，不是真实用户日志；没有人工盲评。
2. 只有一个模型、一个 seed、一个本地嵌入；不能外推到所有中文模型。
3. 事实抽取是规则兜底；复杂多对象/多项目冲突仍可能错。
4. 语义合并阈值 0.90 未做人工标注；保守意味着漏合并。
5. 检索仍是内存线性扫描；SQLite 只改持久化。
